# Pharmacy Prescription and Medicine Stock Management System

A full-stack pharmacy management application for managing medicines, inventory, purchases, sales, prescriptions, customers, suppliers, manufacturers, payments, and stock movements.

## Tech Stack

### Frontend
- React
- Vite
- Tailwind CSS
- Axios
- Recharts

### Backend
- Node.js
- Express.js
- MySQL
- mysql2

## Features

- Dashboard
- Medicine Management
- Category Management
- Manufacturer Management
- Supplier Management
- Purchase Management
- Inventory Management
- Stock Movement Tracking
- Customer Management
- Prescription Management
- Point of Sale
- Payment Management
- Sales Reports
- Purchase Reports
- Low Stock Alerts
- Medicine Expiry Alerts

## Database

The application uses MySQL with the following major entities:

- Category
- Medicine
- Manufacturer
- Supplier
- Batch
- Purchase
- Customer
- Prescription
- Sale
- Sale Item
- Payment
- Stock Movement

## Architecture

React Frontend
↓
Node.js + Express REST API
↓
MySQL Database
